Get AdBlock ↗ How it works
Opens the official Chrome Web Store listing.

Install in 3 easy steps

Follow these instructions to get started.

01

Open the store

Click the "Get AdBlock" button above to open AdBlock's listing in the Chrome Web Store. It is not blocked on school computor.

02

Add the extension

Click "Add to Chrome" on the listing. Review the permissions and select "Add extension" if you agree.

03

Start browsing

Once installation finishes, visit a website. AdBlock can begin filtering ads automatically.

💡 Helpful tip

Can't find the AdBlock icon? Click the puzzle-piece Extensions button near Chrome's address bar. You can pin AdBlock there for easier access.
